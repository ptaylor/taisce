Taisce

Markdown notes in your own Dropbox

Taisce shows the files in its own folder in your Dropbox and edits them in place. It cannot see the rest of your account.

    How to use Taisce

    Tap any paragraph to edit it. The Markdown you type is the formatting:

    • ## A heading — a heading
    • **bold**, *italic*, `code`
    • - item — a list; - [ ] item — a task you can tick
    • [text](https://example.com) — a link

    There is no Save button: edits save by themselves, about a second after you stop typing. Leave a block to see it rendered again.

    Install on a phone

    • Android / desktop: browser menu → Install app (or Add to Home screen).
    • iOS: Share → Add to Home Screen. There is no install prompt on iOS.
