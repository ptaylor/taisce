View and edit Markdown files in your Dropbox account

Taisce allows you to easily create, view and edit Markdown files in your Dropbox account. It cannot see any other files in your account.

      taisce — Irish: a hoard, a store, a treasure.

      How to use it

      Tap any paragraph to edit it. The Markdown you type is the formatting:

      • ## A heading — a heading
      • **bold**, *italic*, `code`
      • - item — a list; - [ ] item — a task you can tick
      • https://example.com on its own is a link too, and so is an email address — no brackets needed.
      • [text](https://example.com) — a link with your own words. Tap a rendered link to change where it points, copy it or remove it. To link words you have already written, select them and paste the address over them.

      There is no Save button: edits save by themselves, about a second after you stop typing. Leave a block to see it rendered again.

      Type / at the start of a line for templates — task list, code block, table, quote and more. Keep typing to filter, then Enter.

      Undo and pictures

      • Undo sits at the bottom right while a note is open (⌘Z / Ctrl+Z on a keyboard, shift for redo). One step per block edit.
      • Paste a picture into a note: it uploads to the _assets folder beside the note and links itself in.
      • Tap a picture to see it full size (View) or delete it. Deleting a picture asks first, then removes both the file and the reference to it in the note; nothing else in the note changes.

      Files and folders

      • + creates a file or a folder in the folder you are looking at.
      • Tap a folder to go into it. The back arrow brings you up a level; two levels down, a trail at the top lets you jump straight to an outer folder.
      • Tap the Recent heading to fold that list away. It is open to begin with.
      • Only Markdown files are listed. Other files in the folder are left alone.
      • Anything whose name starts with _ is hidden from the list and from search — that is what keeps the _assets folder out of the way. Taisce will not create a name starting with _, so nothing can be hidden by accident.
      • Delete (bottom right of a note, the trash can) asks first, naming the file, and then moves it to the Dropbox trash — where it can be restored at dropbox.com until the trash expires. The pictures that note links to go with it; pictures belonging to other notes do not.
      • Share (bottom right of a note) creates a read-only Dropbox link and offers to copy it or hand it to the phone's share sheet. Anyone with the link can read the note; revoke it in Dropbox to stop that.

      Install on a phone

      • Android / desktop: browser menu → Install app (or Add to Home screen).
      • iOS: Share → Add to Home Screen. There is no install prompt on iOS.

      Usage is measured with GoatCounter — no cookies, no personal data, and nothing about your notes. The demo is not counted.
