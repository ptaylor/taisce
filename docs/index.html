Taisce — guide How it works, and how to install it

Markdown notes in your Dropbox account

Taisce shows the Markdown files in its own folder in your Dropbox account and edits them where you read them. It never sees the rest of your account, there is no account with us, and no server of ours in the middle.

Editing

  • Tap a block — a heading, a paragraph, a list — to edit just that block. Leave it and it renders again.
  • The Markdown you type is the formatting. There is no toolbar to learn.
  • No Save button. Edits save about a second after you stop typing, and when you put the app away.
  • Tap a task item to check or uncheck it. That is an edit like any other, and a finished item is struck through.
  • Finished with a block? Tap the tick at its top right corner (or press Esc) and it renders again.

Undo and pictures

  • Undo and redo are the two round buttons at the bottom right while a note is open. On a keyboard, Cmd/Ctrl+Z undoes and Shift+Cmd/Ctrl+Z (or Ctrl+Y) redoes. Each block edit counts as one step, and the number of steps kept is configurable in Settings.
  • Paste a picture into a note and it is uploaded to an assets folder beside the note, then linked in as ![](assets/…). The link is relative, so the note also works in any other Markdown editor that can see the same folder.

Templates

Type / at the start of an empty line to get a menu of templates: task list, bullet list, numbered list, headings, code block, quote, table, divider and link. Keep typing after the slash to filter (/task), use the arrow keys to choose, and press Enter. A slash anywhere else in a sentence is just a slash.

Links

A link belongs in a sentence, so Taisce edits one where it sits. Tap a rendered link and a small editor opens beside it: change the words, change the address, copy it, open it in a new tab, or remove the link and keep the words. The rest of the block is left exactly as it was written.

To link words you have already written, select them while the block is open for editing and paste the address over the selection; the address becomes the destination of the words you selected. Writing [words](address) by hand still works too.

An address typed on its own needs no markup: https://example.com, www.example.com, ftp://… and an email address all become links as soon as the block is left, and each one opens the same editor when tapped.

Files, folders and finding things

  • The home screen shows the files you changed most recently, then the top level of the folder. Recent is a heading you can fold away — tap it — and it is open to begin with. How many recent files it shows is configurable under Settings.
  • Search by file name across every folder. The folder a match lives in is shown beside it.
  • + creates a file or a folder in the folder you are looking at; open a folder to nest inside it.
  • The back arrow takes you back up a level. Two levels down, the trail at the top appears as well, so you can jump straight to an outer folder.
  • Only Markdown files are listed. Other files are left alone.

Install it like an app

Taisce is a PWA. Served over HTTPS it installs to a home screen and keeps working when the connection is flaky.

  • Android / desktop: open the site, then use the browser menu → Install app (or Add to Home screen).
  • iOS: there is no install prompt. Use Share → Add to Home Screen.

Sharing a file

The share button in the corner of a note asks Dropbox for a shared link to that file and offers it two ways: copy it, or hand it to your phone's own share sheet. The link is read-only, and it is public — anyone who has it can read the note, without a Dropbox account and without Taisce. Dropbox shows them the Markdown text as written, not the rendered page.

Sharing does not copy the file or change it. The same link is reused each time you share the same note, and revoking it in Dropbox — or deleting the file — stops it working.

Disconnecting

Settings → Disconnect asks Dropbox to revoke the app’s access as well as forgetting it on this device; you will authorise again next time. Your files are never touched. The token is kept in this browser's local storage, which is why Taisce loads no third-party scripts and sanitises everything it renders. Usage is counted anonymously with GoatCounter — event names only, never the contents of a note; see the privacy policy.
